
# Predictive Maintenance using Machine Learning

## Project Overview

This project aims to detect machine failures using machine learning classification algorithms.

The project uses the AI4I 2020 Predictive Maintenance Dataset, which contains 10,000 synthetic observations of industrial machine operating conditions.

## Objectives

- Explore and visualize the dataset.
- Preprocess the data for machine learning.
- Train Logistic Regression and Random Forest models.
- Evaluate and compare model performance.
- Analyze the results.

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Dataset

AI4I 2020 Predictive Maintenance Dataset  
Source: https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset
